# Proyecto de Validación de Archivos

Este proyecto valida la extensión y el tamaño de los archivos antes de que se suban al servidor.

### Características:
- Permite solo los siguientes tipos de archivo: `.pdf`, `.png`, `.jpg`, `.docx`, `.doc`, `.xlsx`, `.zip`.
- Limita el tamaño máximo de archivo a 60 MB.
- Utiliza **jQuery** y **SweetAlert** para mostrar mensajes de error.

### Instrucciones:
1. Clona este repositorio.
2. Abre el archivo `index.html` en tu navegador para probar la validación de archivos.
